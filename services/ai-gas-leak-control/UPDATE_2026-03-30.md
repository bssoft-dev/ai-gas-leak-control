# AI 가스 누출 자동제어 업데이트 요약 (2026-03-30)

목표: `개발견적서.xlsx` 기능목록 대비 구현율을 **약 45%** 수준으로 끌어올리기 위해, 임계(3단계)·유예·유예취소·제어이력·금일사용량·도면 내 밸브 마커·관제 요약/알림·정책 API 등을 추가 구현했습니다.

---

## 1) 추가 구현(기능 관점)

### 1.1 3단계 임계치 + 유예 + 유예 취소
- `Level1(주의)`, `Level2(경고·사이렌)`, `Level3(위험·밸브 차단)`을 `policy`로 관리
- Level3는 `grace_seconds` 동안 자동차단을 유예한 뒤, 유예 시간이 지나면 밸브(차단 상태)를 자동 전환
- 사용자가 유예를 중단할 수 있도록 `auto_shutdown_deadline` 취소 기능 추가

### 1.2 위험 단계(risk_level) 산정 및 관제 반영
- `sensor_type = concentration(가스 농도)` 값(없으면 시뮬 농도)을 기준으로 최대 농도를 취합하여 `risk_level`(0~3)을 계산
- `risk_level`에 따라 `alarm_beacon_on`, `alarm_siren_on`, `zones[].status`를 갱신

### 1.3 제어 이력(control_history)
- 자동/수동/정책 저장/유예 취소 등 제어 동작을 `data/ai_gas_leak/control_history.json`에 저장
- UI에서 `control-history` API로 최신순 조회

### 1.4 금일 가스 사용량 추정(daily usage)
- 유량 시뮬 값 기준으로 금일 누적 사용량을 `data/ai_gas_leak/daily_usage.json`에 적산(추정)
- UI에서 `daily-usage` API로 조회

### 1.5 도면 내 솔레노이드 밸브 마커 + 편집 모드
- 도면 포인트 저장 포맷을 확장해 `valves`를 함께 저장
- UI에서 도면 배치 모드를 `센서`/`밸브`로 분리하여, 밸브 위치도 도면 위에 표시

### 1.6 브라우저 알림(위험 단계 2 이상)
- `risk_level >= 2` 상태 진입 시 브라우저 Notification으로 알림 시도(권한 승인 시)

## 2) API/이벤트 변경 사항

### 2.1 UI 서버(API)
- `GET /api/gas-leak/control-history`: 제어 이력 조회(최신순)
- `GET /api/gas-leak/daily-usage`: 금일 사용량 추정 조회
- `POST /api/gas-leak/policy`: `Level1~3` 임계치 및 `grace_seconds` 저장(이벤트 발행)
- `POST /api/gas-leak/cancel-auto-shutdown`: 자동차단 유예 취소(이벤트 발행)
- `GET /api/gas-leak/drawings/{drawing_id}`: `{ sensors, valves }`를 함께 반환
- `GET /api/gas-leak/state`: `policy`, `risk_level`, `auto_shutdown_deadline` 등 기본값 포함하도록 확장

### 2.2 이벤트/파이프라인(service.yaml)
- 신규 이벤트/파이프라인 추가
  - `GAS_LEAK_POLICY_SAVE` → 정책 저장 처리
  - `GAS_LEAK_CANCEL_AUTO_SHUTDOWN` → 유예 취소 처리
- 결과 이벤트
  - `GAS_LEAK_POLICY_SAVE_RESULT`
  - `GAS_LEAK_CANCEL_AUTO_SHUTDOWN_RESULT`

## 3) 데이터 포맷 변경(호환)

### 3.1 도면 points 파일 구조
- 기존: `points/{drawing_id}.json` = `[{sensor...}, ...]`
- 변경: `points/{drawing_id}.json` = `{ "sensors": [...], "valves": [...] }`
- 로딩 시 **구버전 배열 포맷도 sensors로 간주**하도록 처리하여 하위 호환을 유지했습니다.
